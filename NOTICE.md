## What this project holds about the people who use it

Nothing.

Giving a Jellyfin server this catalogue's address means the server fetches a
file. Nothing about the server, the people using it, or what is in their
libraries is sent anywhere, and the file that comes back is the same file for
every server, with no value in it that differs between operators.

Serving a file means receiving a request, so the hosting provider receives one
each time. The site is served by GitHub Pages, whatever GitHub keeps about those
requests is GitHub's under GitHub's own terms, and this project neither has
access to it nor adds anything on top: no analytics, no counter, no log of its
own. `decisions/data-posture.md` is the rule and what it rules out.

The plugins the catalogue lists are separate projects under their own terms, and
what each one does with data is its own to describe. Listing something is not a
statement about its behaviour. Personal data stays on the operator's host unless
the operator configures a plugin to send it somewhere, which is a thing set up
deliberately and never a default: another server's address entered in a setting,
an invitation issued outside the household, a synchronisation target pointed at
a machine that is not yours.
